Catatan tiap supplier

      
    
        
  • Lhie: order dibayar penuh dari saldo Lhie (IDR/USD, tidak bisa dibelah). Stok informasional, checkout recheck harga/stok. Pengiriman async (not_ready → processing → complete). Tombol “Cek Delivery” ada di detail pesanan.
    • 
        
  • BuyMail: Gmail, modal contoh Rp4.800/akun, live-check 10–30 detik, refund maks 2 jam (screenshot HP). API terbuka setelah total deposit Rp100.000.
    • 
        
  • Fireflazz: top-up game H2H, deposit pertama min Rp100.000 QRIS, gagal = saldo kembali. Toko Anggara: anggaratopup.fireflazz.com (saldo Rp0 saat dicek 24 Nov 2026). Detail endpoint H2H ada di dashboard Fireflazz — samakan di kode sebelum jualan.
    • 
        
  • Pterodactyl: jual panel, bot create user + server otomatis. Server habis masa aktif di-suspend (tidak dihapus).

Manajemen Tombol

      
Tombol default (Katalog, Cek Pesanan, Bantuan, Beli Sekarang, Kembali, Ya Bayar, Batal) tidak bisa dihapus — hanya bisa diedit / disembunyikan / diurutkan. Tombol tambahan bisa dihapus. Tombol link: isi aksi url + kolom Target dengan linknya (mis. saluran WA, Telegram, website) — tombol link muncul di pesan "🔗 Link Penting" terpisah. Target kosong = tombol disembunyikan. Perhatian: WhatsApp maks 3 tombol balasan dan 3 tombol link per pesan — panel memperingatkan kalau melebihi.

Broadcast

      
Hanya ke subscriber yang opt-in (pernah menyapa bot). Telegram = jalur aman. WhatsApp dikirim pelan (jeda 3 detik) untuk mengurangi risiko ban. Maks 100 penerima per kirim.
